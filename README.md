# WAD Assignment 1

## Assignment Title and Number
**Web Application Development (WAD) — Assignment 1**

## Assignment Description and Objectives
This repository contains a static multi-page departmental website built for WAD Assignment 1. The assignment demonstrates core front-end development skills by creating structured web pages, shared styling, and inter-page navigation.

### Objectives
- Build a multi-page website using semantic HTML.
- Apply consistent styling with reusable CSS.
- Use navigation and linked resources across pages.
- Organize files in a clean academic project structure.

## Requirements and Specifications
- Create multiple HTML pages for different sections of the website.
- Use a shared stylesheet for common layout and design.
- Include internal navigation links between pages.
- Use images and content blocks relevant to the selected theme.
- Ensure pages are viewable in modern browsers.

## Technologies Used
- **HTML5**
- **CSS3**
- **JavaScript** (minimal/inline usage where needed)

## How to Run / View the Assignment
1. Clone or download this repository.
2. Open `index.html` in any modern browser (Chrome, Edge, Firefox).
3. Use the navigation menu to browse other pages.

> Tip: You can also use a simple local server (optional), e.g. `python -m http.server`, then open `http://localhost:8000`.

## Features Implemented
- Multi-page academic website layout
- Shared header, footer, and navigation styling
- Department-focused sections (academics, faculty, research, admissions, funded projects, etc.)
- Image-based content presentation
- Responsive-friendly layout patterns (flexbox and fluid image widths in several pages)

## How to Test the Application
Since this is a static front-end assignment, testing is primarily manual:
1. Open `index.html` and verify page loads without broken layout.
2. Click all navigation links and confirm page transitions.
3. Verify CSS is applied consistently across pages.
4. Check image rendering and text readability.
5. Resize browser window to verify basic responsiveness.
